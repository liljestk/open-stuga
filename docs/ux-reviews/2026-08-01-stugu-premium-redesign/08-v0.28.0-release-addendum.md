# Stugu 0.28.0 release addendum

Date: 1 August 2026

Scope: responsive web, local API, appliance containers, and Raspberry Pi OTA artifacts

Deferred: iOS acceptance and Apple binary distribution

This addendum supersedes overlapping final counts and the earlier conditional posture in
the frozen review tranche. The audit registers remain historical evidence.

## Final receipts

- Root `npm test`: pass, including API 744/744 across 121 files, bug-report relay
  4/4, Tapo runner 37/37, web 958/958 across 140 files, and spatial layers 34/34.
- Root `npm run typecheck`, `npm run build`, `npm run smoke:built-api`,
  `npm run version:check`, and `git diff --check`: pass.
- Built API: Stugu 0.28.0 on Node 22.22.3.
- Web catalogue: 4,159 keys with exact EN/FI/SV parity and placeholder checks.
- Native portable readiness: pass; Xcode and Apple device acceptance remain
  deferred by scope.

## Review findings resolved

Claude completed an earlier untruncated core review. Its two medium
browser-storage concerns were rechecked against the documented security
contract and focused tests: active account state is deliberately purged on
logout/session expiry, and no-email service/MCP principals are not browser
actors. A final Claude/Opus attempt over the whole 283-file release diff was
safety-truncated and timed out after 420 seconds without returning findings;
it is recorded as partial provider coverage, not a pass.

The integrated senior review found eight P0–P2 issues; all were fixed and
regression-tested:

1. sensitive export, backup, setup-diagnostic, and sensor-label authorization;
2. Guest self-service bug-report access;
3. Stuguby grant and command retirement when a Home is hidden;
4. removal of the MCP hard-delete path that bypassed Home retirement;
5. preservation of historical weather observations when inheritance changes;
6. playbook visibility for global and alert-specific routes;
7. Live Home View focus restoration after collapsing; and
8. database-level Home scoping before sensor-gap limiting.

Live measurement streams also send an immediate connection comment so
buffering proxies do not create a false reconnect state.

## Performance and stability evidence

- Default Home history fan-out fell from 60 requests to 1 in the 10-sensor,
  six-metric fixture; opening History deliberately loads the detailed 60.
- A hidden Live Home View performs zero spatial requests instead of four;
  returning refreshes once and obsolete overlapping refreshes are aborted.
- Home analytics benchmark: cold 52–74 ms; warm median 2.9 ms; warm p95 3.7 ms;
  1,572-byte response.
- Concurrent startup endpoint p95 was approximately 6.6–9.3 ms, with maximum
  at or below 10.8 ms in the local benchmark.
- Largest final production chunks are split by feature/vendor; the largest
  gzip payloads are Finnish 80.24 kB, i18n 77.23 kB, React 59.65 kB, and global
  CSS 56.01 kB.

True LCP, INP, and CLS were not captured because the required Chrome DevTools
performance integration is unavailable in this environment. No score is
inferred from bundle or API measurements.

## Browser and responsive evidence

The earlier completed production Chromium tranche covered the 27 requested
routes at 320 × 568, 390 × 844, 768 × 1024, and 1024 × 768. After the final
security and stability fixes, the rebuilt desktop runtime was rechecked on the
six highest-risk routes: Workspace overview, Property, Home, Home electricity,
Weather setup, and People. Each retained one `h1` and one `main` and avoided the
route error boundary. Responsive
layout, drawer, focus, URL-state, and long-copy behavior remain covered by the
final automated web suite.

Not claimed as complete: Firefox, Safari/WebKit, assistive technologies,
forced-colour and colour-vision modes, production identities and vendor
hardware, long-duration use, or representative-user research.

## Artifact policy

All local repository changes are included in 0.28.0. Multi-architecture
application images and Raspberry Pi OTA artifacts are publishable. The factory
image is built and retained locally; it must not be attached to the public
release. Source and public release artifacts are versioned 0.28.0.
